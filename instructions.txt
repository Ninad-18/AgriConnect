AgriConnect — Commands to Run Every Time
Step 1: Start Docker databases
Open PowerShell Terminal 1:
cd C:\Users\NINAD\OneDrive\Desktop\app
docker compose up -d postgres mongodb redis


Step 2: Start the backend
Open PowerShell Terminal 2:
cd C:\Users\NINAD\OneDrive\Desktop\app\backend
npm run dev


Keep this terminal open.
Step 3: Start the frontend
Open PowerShell Terminal 3:
cd C:\Users\NINAD\OneDrive\Desktop\app\frontend
npm run dev


Keep this terminal open too.
Step 4: Open the application
Frontend — AgriConnect UI
http://localhost:5173

Open

Backend health check
http://localhost:5000/health

Check

Remember:
- Run the Docker command first, then backend, then frontend.
- You only need npm install again if dependencies change or you newly set up the project.
- To stop the backend/frontend, press Ctrl + C in their terminals.
- To stop the databases, run docker compose stop from the project root. You don't need to stop them every day.
- Never use docker compose down -v unless you intentionally want to remove the database volumes and their stored data.
