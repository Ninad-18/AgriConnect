1. ENVIRONMENT VARIABLES
Backend (backend\.env) — already exists. Fill required:
  - JWT_SECRET: generate a long random string
      node -e "require('crypto').randomBytes(32).toString('hex')"
  - CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY, CLOUDINARY_API_SECRET  (https://cloudinary.com)
  - RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, RAZORPAY_WEBHOOK_SECRET     (https://dashboard.razorpay.com) — use TEST keys for dev
  - FIREBASE_SERVICE_ACCOUNT_PATH  (optional, FCM)
  - GOOGLE_MAPS_API_KEY            (optional)

Frontend (frontend\.env):
  VITE_API_BASE_URL=http://localhost:5000
  VITE_RAZORPAY_KEY_ID=<same as RAZORPAY_KEY_ID>

NOTE: .env files are gitignored. Never commit secrets.

2. DATABASES (MUST BE RUNNING)
Option A — Docker (recommended if Docker Desktop is installed/running)
  docker compose up -d postgres mongodb redis
  # wait ~5s for DBs to be ready

Option B — Native (no Docker)
  Start PostgreSQL (port 5432), MongoDB (27017), Redis (6379)
  Ensure credentials match backend\.env (defaults: agriconnect/agriconnect)

Verify ports: Postgres 5432, Mongo 27017, Redis 6379 should be listening.

6. DOCKER COMPOSE NOTES
docker-compose.yml defines: postgres, mongodb, redis, backend, frontend.
- If containers don't exist: docker compose up -d creates/pulls/builds and starts them.
- Uses internal hostnames (postgres/mongodb/redis) for service-to-service networking; localhost for host access.
- Volumes: pgdata, mongodata (persist data). No secrets in compose file.
- Safe to commit to GitHub. Do NOT commit .env files.

7. TROUBLESHOOTING
- DB connection errors: ensure DBs running on correct ports; check DATABASE_URL/MONGO_URL/REDIS_URL
- Prisma issues: 
px prisma generate after schema changes
- Port in use (5000/5173): change PORT in backend/.env or Vite port
- Razorpay webhook (dev): use ngrok to expose localhost:5000 for webhook testing, set RAZORPAY_WEBHOOK_SECRET

8. USEFUL COMMANDS
Backend: npm run dev | npm run build | npm run typecheck | npx prisma studio
Frontend: npm run dev | npm run build | npm run typecheck
